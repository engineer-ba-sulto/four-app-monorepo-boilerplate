**ルート**

- `dev:sp` を `bun run --filter sp dev` に修正（`bun --cwd apps/sp run dev` は Bun 1.3 で script が実行されないため）
- `dev:web` / `dev:lp` も `bun run --cwd <app> <script>` 形式に修正

### tsconfig 互換メモ

`expo/tsconfig.base` の代わりに `react.json` を extends。Expo 固有の `customConditions: ["react-native"]` と `resolveJsonModule` を `compilerOptions` で上書き追加。型チェックは通過。

### Bun first + Expo 逃げ道（Phase 4 本文候補）

- パッケージ管理は Bun（`bun install`）を正とする
- EAS Build / `npx expo prebuild` / ネイティブ toolchain で Bun 起因の不具合が出た場合は、[Expo 公式 CLI 手順](https://docs.expo.dev/)に従い npm/yarn で該当コマンドのみ実行する逃げ道を README に記載する
- クライアント env は `EXPO_PUBLIC_*` プレフィックス（例: `EXPO_PUBLIC_API_URL`）
